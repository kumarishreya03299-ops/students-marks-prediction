# Student Marks Prediction
A Machine Learning project that predicts a student's marks based on the number of courses and study time.

# Features
- Predicts student marks using Machine Learning
- Simple and easy-to-use Streamlit interface
- Takes study time as input
- Displays the predicted marks

# Technologies Used
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Streamlit
- Joblib

# Where Python is Used
Python is the main programming language used in this project.
Python is used for:
- Reading the dataset
- Preparing the data
- Training the Machine Learning model
- Testing the model
- Predicting student marks
- Saving and loading the trained model
- Creating the Streamlit web application

# Libraries Used
Pandas: Pandas is used to read and work with the dataset.

# Scikit-learn
Scikit-learn is used to create and train the Linear Regression model.

# Matplotlib
Matplotlib is used to create graphs for comparing actual and predicted marks.

# Streamlit
Streamlit is used to create the web interface for the Machine Learning model.

# Joblib
Joblib is used to save and load the trained Machine Learning model.

# Machine Learning Model
This project uses Linear Regression to predict student marks based on study hours.

# How to Run
1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Install the required libraries: pip install -r requirements.txt
4. Run the Streamlit application: streamlit run app.py
5. Open the link shown in the terminal to use the application.
